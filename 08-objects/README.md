# Objects & Object References

JavaScript Deep Dive — Day 08

## Overview

Objects are one of the most important data structures in JavaScript.

In this topic, we learned how objects store related data, how properties are accessed and modified, and how JavaScript handles object references.

The main focus was understanding the difference between copying a primitive value and copying a reference to an object.

## Topics Covered

- JavaScript objects
- Object properties
- Dot notation
- Bracket notation
- Adding, updating, and deleting properties
- Primitive values vs object references
- Object assignment
- Object comparison
- Nested objects
- Shared references
- Objects passed to functions
- Connection between objects and previously learned concepts

## Key Learning

When an object is assigned to another variable, JavaScript does not create another independent object.

Both variables can refer to the same object.
