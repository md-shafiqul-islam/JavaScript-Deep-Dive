# Functions, Callbacks & Higher-Order Functions

## Overview

This topic covers how JavaScript treats functions as values and how functions can be passed to or returned from other functions.

## Topics Covered

- Functions as values
- First-class functions
- Callback functions
- Higher-order functions
- Functions returning functions
- `forEach()`
- `map()`
- `filter()`
- `reduce()`
- Arrow functions as callbacks
- Callbacks and `this`
- Closures with higher-order functions

## Key Concepts

- Functions can be stored in variables.
- Functions can be passed as arguments.
- Functions can be returned from other functions.
- A callback is a function passed to another function.
- A higher-order function receives or returns a function.
- `map()` transforms elements.
- `filter()` selects elements.
- `reduce()` accumulates values.
- Returned functions can retain access to outer bindings through closures.
