# JavaScript Event Loop

This folder contains my learning materials for JavaScript's Event Loop.

## Topics Covered

- Synchronous execution
- Call Stack
- Host environment
- `setTimeout()`
- Task/Macrotask Queue
- Microtask Queue
- Promise callbacks
- Event Loop execution order

## Key Learning

JavaScript executes synchronous code first.

After the current synchronous code finishes, pending microtasks are processed before the next task from the Task Queue.
